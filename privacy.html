Privacy Policy

Last updated: 26 November 2026

LINE Drive Saver ("the app") is a personal tool run by its owner (GitHub user tumngobTH) to save files from LINE group chats into the owner's own Google Drive. This policy explains what data the app handles and how.

1. Google user data

  • What is accessed: the app uses the Google Drive API with the owner's authorization to find and create folders, upload files, and read and update one small mapping file (line-drive-mapping.json) inside the folder the owner chooses.
  • How it is used: only to store files shared in LINE groups where the bot is a member, and to remember which Drive folder belongs to which chat. The app does not read, change or delete any other files in the owner's Drive.
  • Sharing: Google user data is not sold, shared with third parties, used for advertising, or used to train AI or machine-learning models.
  • Storage: the OAuth refresh token is stored encrypted in Google Cloud Secret Manager and used only by the app's server on Google Cloud Run.

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

2. LINE data

For messages in groups where the bot is a member, the app receives from LINE: group and user IDs, message IDs, timestamps, and the content of shared media and files. Media and files are passed straight through to Google Drive and are not kept on the server. Text messages are ignored, apart from bot commands such as /folder and /help.

3. Logs

Technical logs (such as errors and message IDs) are kept in Google Cloud Logging for troubleshooting and are deleted automatically according to Google Cloud's default retention.

4. Your choices

  • Remove the bot from a LINE group to stop new files from that group being saved.
  • The owner can revoke the app's Drive access at any time at myaccount.google.com/permissions.
  • Saved files can be deleted from Google Drive at any time.

5. Contact

Questions: open an issue at github.com/tumngobTH/line-drive-saver/issues.
