LINE Drive Saver

A personal LINE bot that saves files shared in LINE group chats to the owner's Google Drive.

What it does

When a photo, video, audio clip or file is shared in a LINE group the bot has been added to, the bot saves a copy to a folder in the owner's own Google Drive: one folder per chat, with each file name prefixed by the date it was shared (yyyymmdd).

บอท LINE สำหรับใช้ส่วนตัว ทำหน้าที่บันทึกไฟล์ (รูป วิดีโอ เสียง เอกสาร) ที่ส่งในกลุ่ม LINE ลงใน Google Drive ของเจ้าของบอท แยกโฟลเดอร์ตามแชท และตั้งชื่อไฟล์ขึ้นต้นด้วยวันที่ส่ง

Google user data

The app asks for access to Google Drive only so it can create folders and upload these files into the owner's Drive. See the Privacy Policy for details.
